# CholuGomitas Web

Landing page académica y comercial para **CholuGomitas**, un proyecto de gomitas saludables a base de cholupa, pectina y stevia.

## Incluye

- Diseño responsive.
- Animaciones con Anime.js.
- Efectos parallax con simpleParallax.js.
- Imágenes extraídas del documento Word.
- Texto adaptado del documento del proyecto.
- Barra de navegación fija.
- Sección de integrantes con las fotos extraídas del documento Word.
- Redes sociales.
- Página independiente para la vista completa del proyecto.
- Descarga del PDF oficial desde “Ver propuesta”.
- Estructura lista para publicar en GitHub Pages.

## Tecnologías

- HTML5.
- CSS3.
- JavaScript.
- Anime.js.
- simpleParallax.js.
- GitHub Pages.

## Cómo correrlo en VS Code

1. Abre la carpeta `cholugomitas-web` en VS Code.
2. Instala la extensión **Live Server**.
3. Abre `index.html`.
4. Haz clic derecho y selecciona **Open with Live Server**.

## Cómo publicarlo en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube todos los archivos del proyecto.
3. Entra a **Settings**.
4. Ve a **Pages**.
5. En **Branch**, selecciona `main`.
6. En carpeta, deja `/root`.
7. Guarda los cambios.
8. Espera el enlace público de GitHub Pages.
